# OpenCockpit

Open-source Enigma2 plugins that integrate streaming services directly into the DVB service architecture, so a streaming channel behaves exactly like a normal TV service: same channel selection, same favourites, same EPG handling.

## Projects
- **[IPTVServiceCockpit](https://github.com/OpenCockpit/IPTVServiceCockpit)** — integrates custom IPTV playlists (M3U8) as providers/favourites.
- **[PlutoTVCockpit](https://github.com/OpenCockpit/PlutoTVCockpit)** — Live-TV and VoD playback of Pluto TV streams.
- **[RakutenTVCockpit](https://github.com/OpenCockpit/RakutenTVCockpit)** — Live-TV playback of Rakuten TV streams.
- **[SamsungTVCockpit](https://github.com/OpenCockpit/SamsungTVCockpit)** — Live-TV playback of Samsung TV Plus streams.

## Installation
Each plugin ships its own install feed - see the individual repo's README for setup instructions.
